## 逐项核对

| 项目 | 实际实现与审查结论 |
| --- | --- |
| 九个等预算槽 | 只接受与协议完全一致的9个证券身份；100%或60%的初始预算除9后取整数分。费用、整手、1%成交量和价格边界一起约束数量。某槽未买入不重分配，不在后来补买。目标100%不等于实际100%投资。 |
| 日期化费用 | 买入使用首个目标交易日费用；假设期末卖出费用使用期末日期费用。复用 `profile_for` 要求恰好一个有效档位。佣金最低收费、含佣交易所费用、另收项目、卖出印花税与滑点分开；本审查核对冻结配置的应用，不重新认证真实券商费率或法律适用。 |
| 现金与锁定 | 初次买入计T+1；登记日锁定持股权益。除权日按旧股数计算税后现金应收，到账日前不能花；送转新增股份在除权日计市值、真实上市日前不能作为可卖数量。 |
| 送转与停牌 | 公司行动按含税派息和送转比例变换旧价格；停牌延用因果已有估值。分数股、未知日期、同日多行动组合不擅自简化，明确拒绝或使结果失效。 |
| 分红不重计 | `ACTION_EX`不改变现金；到账才产生`DIVIDEND_PAYMENT`，不再投资。净值由现金＋持仓市值＋应收组成；到账只是应收到现金的转换。 |
| 期末处理 | 保留持仓市值，不虚构卖出。假设卖出费仅对已解锁且满足最后交易日条件的数量计算；停牌/涨跌停/成交量等不满足时该股票估算为NULL。`terminal_fee_estimate_complete`明确部分估算，费用不从已报告收益二次扣除。 |
| 跨年归因 | 每年以此前连续账户的期末净值为起点，首年以初始资金为起点；不年度重置或再平衡。年度回撤是本年度起始净值与本年高点定义下的回撤，不能代替整段历史最大回撤。 |
| 中途失败 | 逐日循环内缺行情、非整数权益等错误保留先前买入、账本、部分曲线与持仓，并标`FAILED_PARTIAL_INVALID`；净收益/最大回撤为NULL，年度正式汇总为空。不能把部分曲线作为完整成绩。 |

## 独立手算：仅合成会计例子

独立构造9只合成证券、虚拟本金90,000元，每股20元、每手100股。佣金0.03%、最低5元，另收0.001%、卖出税0.05%、无滑点，均为**本例合成假设**，不是实际账户或新生产默认值。每个预算槽10,000元，500股含费超额，因此每槽买400股：每槽支出8,005.08元，9笔费用共45.72元，现金17,954.28元，首日净值89,954.28元。

其中一只登记400股，次日每股派0.50元、每股送0.25股，模拟税20%，新增100股至下一年1月5日才可卖；除权价15.60元。新增股份已计市值但锁定，现金应收160元：该股市值7,800元，组合除权日净值89,914.28元，比前日少40元模拟税。1月2日到账后现金18,114.28元，应收归零，净值不再次增加；期末500股中400股可卖、100股锁定。仅对可卖400股估计卖出费用8.18元，未执行该卖单。2026年起始净值仍为89,914.28元，例内该年收益0，不重置本金。

以上12个独立预期断言均通过。该例验证资金、应收和锁定会计，不包含真实市场资料，不证明收益能力。

## 测试与剩余边界

- 原实现16项合成测试复跑通过：`python -B -m unittest tools.long_forward.tests.test_benchmarks`。
- 独立手算12项断言与上述16项测试分别记录，不混成28个唯一测试用例。
- 基准只消费上游已准入Case，不自行证明数据许可、PIT、公司行动完整性或全市场历史证券范围。
- 协议/权益结构错误在进入逐日执行前直接拒绝。另一个防御性限制是期末费用估算处若收到上游漏检的无有效费用档位，会抛异常而非返回部分基准结果；当前已冻结费用覆盖和上游Case检查是其前提。调用方必须保留原Case/引擎结果并记录AnalysisError，不把异常视作无交易。
- 界面展示失败对照时必须同时显示其失败状态；部分持仓、部分曲线和NULL收益不能被当成完整期末成绩。
