## 实现一致与规则含义分开

1. **最后40交易日没有额外多禁一天。** 设末日索引L，决策日i条件L−i≤40抑制买入候选；由于次日执行j=i+1，最后允许决策为L−41，执行L−40。被禁止的执行日是L−39至L，恰40日。实际最后允许决策2026-08-03、执行2026-08-04；2026-08-05至09-30无新开仓。真正最后一笔买入2026-07-30，是信号/约束结果，不是移动尾部区间。
2. **20/40是收盘决策阈值。** 达龄后下一可执行开盘才卖出；若受阻继续持仓。因此不是“必在第40日内卖掉”。20也不是最低持有时间，止损/SMA失效可以提前退出。本run的卖出理由为SMA20失效31、2ATR收盘止损2、40日退出2，无day20非正收益退出。
3. **退出理由有优先级与记忆。** 新触发时止损、SMA20、day20条件可能覆盖同日40日标签；已挂起卖单保留首次原因，后续不为了更好解释收益改写原因。复现确认了这个行为，不宣称这种优先级经济上最优。
4. **仓位限制不是盘中保证。** 建仓时旧持仓以因果调整后的上一已知收盘估值，新开仓含费/滑点按开盘代理；不代表所有持仓在实际开盘跳空后仍严格满足同一瞬间的20%/40%/60%。这是现实现和既有口径，未借复核改算法。
