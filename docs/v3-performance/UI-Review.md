# V3 绩效界面审查

本轮沿用现有 `workbench/` 与验证页，没有建立新站、改变策略或重新抓取行情。实现文件为 `workbench/static/app.js`、`style.css`，新增合成展示测试 `workbench/tests/test_performance_ui.py`。历史来源失败、正式历史验证、Forward 仍各自保留，不用 V3 成交结果替换旧状态。

## 默认可读内容

- 同一 `run_id` 的期末人民币净值、模拟收益百分比、最大回撤与完整交易数。
- 每日净值、回撤、持仓暴露 SVG 曲线；数据点可悬停查看日期和值。没有数据时不画零曲线。
- 最大回撤高点日、低点日及是否恢复；按实际逐日净值求展示区间。
- 费用、最低佣金增加额、滑点、现金分红分别列出。最低佣金增加额已包含佣金，滑点已包含成交价，不能再次从净收益扣除。分红仅汇总 `DIVIDEND_PAYMENT`，不将 RECORD/EX 重复当成现金收入。
- 可按证券筛选、分页的逐笔成交与未成交表，以及分红到账表、逐日账户记录。
- `gateway_v3.performance` 在 `status=VERIFIED`、`run_id` 和 `engine_result_hash` 均匹配时，展示独立复算的公司、样本组净利润贡献及基准。未有匹配产物时显示待核验，不在前端生成归因或补造基准。
- 技术 JSON、API 矩阵、逐日账户明细收在折叠区；默认不再用巨型 JSON 代替主视图。

金额统一从整数分换算为元；收益率及回撤由 fraction 换算百分比。NULL/undefined/非有限数显示暂无结果，真实零值正常显示。SVG 仅是展示浮点计算；金额和归因的权威值仍为已保存及独立验证的产物。

## 测试与实际页面边界

新增 17 条测试使用合成数据和 Node 内存 DOM，不访问市场、凭证、私有原件或用户浏览器。覆盖元/百分比换算、NULL 与零、非有限值、缺失费用保持未知、回撤日期/恢复、现金分红不重复计入、最低佣金不重复计入、其他 run/hash 拒绝、同运行归因绑定与基准日期一致、SVG 和折叠状态、无数据不画曲线、分页和筛选。

入口：`python -B -m unittest discover -s workbench/tests -p test_performance_ui.py`。JavaScript 语法检查：`node --check workbench/static/app.js`。

这些合成测试不替代真实浏览器验收。本轮已在重启的本机 `http://127.0.0.1:8769/#validation` 上通过 CUA 操作 Safari，加载真实 `VERIFIED` 独立绩效 payload：

2. 实际渲染净值、回撤、暴露三幅 SVG，两个基准与原策略的 241 个日期一致后叠加。

## 解释边界

模拟收益不证明投资有效性、未经触碰样本外表现、原始历史 PIT 或实盘准入。公司贡献比例以组合初始本金为分母，不是该股票自身持有收益率；样本组不是完整行业指数。当前研究评分不会用于重写过去的买入决定。
