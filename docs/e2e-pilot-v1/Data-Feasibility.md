## 单位、复算及修订处理

字段顺序固定为：FY2025收入、同一报表FY2024比较收入、FY2025合并净利润、FY2025合并经营现金流净额。它们分别支持收入增长、现金利润转换率和净利率；不是价格预测概率。

- 全部使用合并净利润，不能用归母净利润除合并现金流。紫金摘要的合并净利润为四个已披露季度“净利润”行的求和，四项原数、求和规则及页码已保存；不是归母净利润相加。
- 中国西电直接取合并报表精确人民币元，未用主要指标的万元四舍五入数。收入取“营业收入”行，与“营业总收入”中的利息等收入区别明示。
- 江西铜业取同一2025报表的已重述2024比较列；调整前数仍在原件，未覆盖。它不证明2024年末当时可见。
- 景旺年报存在后来2026-04-23修订的发现线索。本轮固定读取2026-03-28版本，明确不是已证明最新版本，修订链未关闭。
- 洛钼前部页面字体映射造成文字缺失；金额采用后部可读的合并财务报表附注P179/P185，不以缺字截图猜标签。
- `tools/e2e_pilot/data_audit.py` 再核9份原件哈希、36项数值在指定页的存在性、期间、单位、合并口径、时钟和源版本；以 `fractions.Fraction` 独立精确计算27个比率/归一化分项及3个样本财务代理小计。记录为机器算术复核，不冒充独立人类认证。数值存在性本身不证明行列语义，行列选择仍需原表核对。
