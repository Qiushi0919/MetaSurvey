# 输入、评分与执行链

本轮仅采用 FY2025 同版本合并报表的四项金额。具体公司/页码/URL见 [实际数据审查](Data-Feasibility.md)。所有原件在 Git 外，工作台只返回允许展示的实验派生结果与追溯元数据。

|结果|输入及单位|算法|时点/缺口|
|---|---|---|---|
|营收增长分|同一2025报表收入、2024比较收入；CNY|收入比−1；−20%→0分、+20%→100分，截断|当前取得的2025版比较数，不证明过去首见|
|现金转换分|合并经营现金流/合并净利润|0→0分、1.5→100分；净利润必须为正|不使用归母净利润代替集团分母|
|净利率分|合并净利润/合并营业收入|0→0分、20%→100分|西电分母营业收入不含利息等营业总收入差额|
|公司基本面因子|以上三项|三项等权，缺任一阻断；七因子中权重25%|仅质量分项，不能代替完整公司总分|
|板块财务健康代理|固定3家同样三项分数|每项3家公司等权，再三维等权|不是原九维方法，也不是全行业；不同混合业务差异保留|
|板块/公司风险后总分|适用风险、反证完整性与其余因子|风险未知则NULL|本轮均未形成完整总分|
|受益/催化/趋势/估值/流动性/证据质量|分部收入映射、完整事件窗口、行情/行动、1260估值、成交量单位、固定事实清单|七权重25/20/15/15/10/10/5固定|未取得完整输入，未按剩余权重归一|
|模拟仓位|完整候选、下一可执行价格、ATR20、历史整手、费用|按现金/20%/60%/40%/1%止损预算逐手取最大可行量|当前真实候选不满足；构建器已实际调用但无计划|
|历史运行|许可用途、日历、每日价量及状态/涨跌停/整手/公司行动|独立量价诊断，不引用当下财务评分|准入检查实际执行并阻断；不是已运行真实回测|

证据方向：官方PDF → 原件哈希与实际采集时钟 → 财务输入 → 27分项 → 9基本面小计 / 3样本小计 → 完整总分缺口 → 组合拒绝原因。股票对象绑定相同版本上游板块哈希。每次界面读取重核固定白名单、代码/配置/输入/原件哈希并独立重算显示值。

研究小计展示不产生正式 CandidateSet、Signal、Approval、OrderIntent，也不改变 ResearchCard/BrainPacket 原生合同。冻结的原V0/V01模型与入口继续保留。
