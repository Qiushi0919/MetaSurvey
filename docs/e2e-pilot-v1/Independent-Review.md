# E2E Pilot V1 独立代码与算术复核

审查时间：2026-10-14（Asia/Shanghai）。审查者为本轮独立 Codex 子任务，不是另一个真实人类签名主体。本报告不签发来源认证、数据许可、历史 PIT 或投资有效性证明。

结论：真实当期财务研究有可复算进展；整条研究到真实行情历史模拟的业务目标尚未完成。不能用合成测试通过替代真实历史引擎运行。

## 原件与算术

直接读取九份本地官方披露 PDF 的引用页，逐项对照具名财务行、年度列、单位及合并口径，核对全部 36 个事实。使用独立 `Fraction` 有理数和整数 HALF_EVEN 舍入实现，复算 27 个财务分项、9 个公司财务代理小计、3 个样本篮子财务代理小计；全部与实验计算器一致。另独立复算三个合成价格/ATR 仓位案例的整手数量、费用与计划止损金额，全部一致。这三个例子不是真实策略交易。

关键语义核对：沪电股份使用合并净利润而非归母净利润；江西铜业使用同一 2025 年报中重述的 2024 营收比较列，并保留经营现金流的负号；紫金矿业使用四个非累计季度的合并净利润求和；思源电气和洛阳钼业现金流补充资料的净利润口径为合并集团。PDF 页码为文件物理页，不必等于印刷页码。

原始数值、引用行、分数有理数分子/分母及逐项比较保存在 Git 外 `e2e-pilot-v1-20261014/Independent-Arithmetic.json`。公开报告仅披露核对范围与结论，不复制整份原件。

当前资料使用采集时钟作为当前观察可用时间，`published_at=null`，历史可见性均为 false。文件 hash 可验证字节一致性，不能证明供应方许可或历史首次可见时间。三个篮子均只是三个指定公司的样本；集团业务混合情况不能解释成纯 PCB、纯高压设备或纯铜矿行业财务。

## 结果含义

本轮真实研究记录 `E2E-PILOT-V1-20261014-RESEARCH-01` 有 3 个篮子与 9 家公司。27 个分项和财务代理小计可以展示；公司七因子完整总分和风险调整后的板块总分均仍为 NULL。其余因子和风险证据未齐全，未按剩余权重重算总分。

真实诊断尝试 `E2E-PILOT-V1-20261014-DIAGNOSTIC-ATTEMPT-01` 的结果为 `DATA_BLOCKED`、`run_attempted=true`、`engine_called=false`、完整模拟交易 0、收益与回撤 NULL。实际原因包括历史诊断许可、历史价格可见性、完整日历及执行域尚未准入。`bars=[]` 与 `calendar=[]` 是拒绝把未准入原始数据送进引擎，不是成功跑过真实行情后的空仓结论。

组合构建器被调用，但没有满足完整研究和执行输入条件的候选，因此现金保留 100,000 元、持仓为空。不能称为已选定真实基础组合。合成输入已经验证费用、风险、整手和执行链，真实行情成交尚未实现。

## 代码审查发现

审查中提出两项必须补强的边界：

1. 真实诊断不能仅绑定 protocol hash，还必须绑定冻结的九成员/板块映射及预注册连续区间；否则换样本或挑短窗口仍可能冒用同一协议。持仓数量还需严格为正整数。
2. 读取器应核对 Financial-Inputs 的来源记录 → Capture → 对应 PDF pin 的关系，而不是仅分别核对各文件 hash。

两项已修复并独立复查：真实分支现绑定 method hash、九成员/板块、完整声明日历的首尾与预注册窗口；拒绝负数、零、布尔和非整数持仓数量及重复持仓。读取器现将来源 URL/最终 URL、路径、hash、大小和观察时钟与捕获记录及实际 PDF pin 对齐。初次修复后的 56 个新实验用例与 23 个 E2E 读取器用例全部通过。最终增加结果类型、方法版本、结果晚于输入及重封包防篡改检查后，独立重跑 64 个新实验用例与 23 个 E2E 读取器用例，87 项全部通过；不替代最终跨平台 CI。

## 限制与后续

本独立审查没有执行外部市场 API、读取凭证、改动旧冻结资产或运行正式回测。首次工程测试复核为 44 个唯一 unittest 用例通过；发现边界问题并修复后，最终追加复核 64 个实验用例及 23 个读取器用例。工作台完整套件发现数为 74，其中本独立复核执行新 E2E 读取器的 23 项，其余旧用例结果与最终跨平台 CI、提交以本轮验收报告固定版本为准。

完整目标仍需要同一许可用途下的九成员真实行情及执行域证据、历史时点可见性；完整研究还需要另外六因子与适用风险证据。未获得这些输入前，不应从当前财报回填历史买入，不应把样本财务代理小计当作投资建议或上涨概率。
