# 2万元账户历史适配方法

实验 `CORE40_ACCOUNT20K_HISTORY_V1`，命名空间 `EXPERIMENT:CORE40:ACCOUNT20K_HISTORY_V1`。Owner 于2026-10-20授权本轮账户适配及限定108组搜索。它与实时账户的计划、余额及正在运行参数隔离；历史推荐不自动替换 P009。

本轮重新以2,000,000分现金计算每笔整手数量、风险、费用和净值；不是将10万元结果缩小五倍。最大3只、单股新增20%、总投入60%、样本组40%、含买卖估计费用计划损失1%，入场、阶段20日及最大40日退出均继承原参数实验。ATR倍数同时改变止损及风险数量。原九股保持不变。

佣金为Owner指定的模拟假设：买卖各万2.5，每个独立已成交委托最低5元；含经手费和证管费，尚未经交割单核实。历史执行一单一次成交，未成交不收费。过户费2022-04-29前万0.2、之后万0.1，卖出印花税2023-08-28前千1、之后万5；沿用已封存日期化费用表，10bps基础滑点及30bps压力情景。现金和每个费用分项按Decimal四舍六入五成双至分。印花税与过户费另计，没有重复附加已包含规费。

历史公司行动继续使用已登记 `SIMULATED_FLAT_20_PERCENT` 分红税假设，以可比性为目的。这不是实际差别化分红税额，也不能用于新实时账户。分红、送转、价格变换及可卖日期继续由原捕获资料驱动，账本保留权益及到账。持有对照的长持仓尤其可能被该保守假设低估；本轮不宣称真实税后收益。

## 时间及选择纪律

开发区2021-10-08～2023-12-29；参数选择区2024年；历史检查区2025-01-01～2026-09-30；交易日按已捕获日历落地。各分区独立初始化2万元，无跨区余额或持仓；自然年归因不重置区内账户。保留2021-06-01起预热。所有指标只读当日已处理的因果价格序列；窗口要求动态增长到60日所需61条连续有效记录。

先固定比较P029/P009/P006（各分区及完整五年、10/30bps），再完成108×开发/选择×10/30=432训练情景。固定三组的检查成绩属于已知候选的先验账户适配，不参与搜索选择函数。搜索函数只消费432条开发/选择记录，锁定最多3组后才运行其他锁定组的历史检查，不替补候选。

继承原登记的收益、回撤、开发区、压力及邻近稳定性约束。邻近为单参数移动一格；近似并列0.25个百分点时先回撤、再买卖双边成交额/平均净值的换手、再编号。所有数据均已暴露，标记 `EXPOSED_HISTORY_EXPLORATORY_OPTIMIZATION`，不称未见样本外，不作统计显著性保证。

原版五年末尾40交易日不再新增的规则保留；每个分区同样执行。没有伪造期末卖出，未平仓与应收据实估值。100%及60%目标持有对照在窗口首日按九等份预算、整手含费用下单一次，缺资金不买，不再补买；目标预算不等于实际敞口。对照无策略尾部抑制，因为它只有首日买入。

## 单股依赖

固定P029/P009/P006分别排除九股中的每一只，在三个分区及10/30bps情景完整重跑：9×3×3×2=162次。没有仅扣利润贡献；组内相对强弱按剩余成员重新计算，因此包含成员删除对组选择、排序、数量、费用及现金路径的影响。删除不作为新股票池推荐，也不从中选择最有利的删除结果。

## 工程修正与保全

首次私有epoch在已开始计算后发现：显式Case/Protocol及现金计算均为2万元，但继承RULES元数据仍写10万元。该epoch标记 `INVALIDATED_METADATA_CAPITAL_CONFLICT`，全部代码及部分结果封存。新版本1.0.1删除此旧常数，强制Case与Protocol的正整数初始资金相等。参数、选择规则、数据不变，再冻结后重跑。不能把此技术修正当成新的未见历史。

新版本先用原10万元及原费用复现完整原五年结果，除允许的版本/身份/输入hash外所有经济字段逐字段相等，再运行2万元适配。原V3、五年基线、PARAM_OPT、Forward A、pin/seal及原件均未修改。

## 运行与复核

在仓库根目录：

```sh
python3 -B -m tools.account20k_history.check
python3 -B -m tools.account20k_history.run
python3 -B -m tools.account20k_history.review
python3 -B -m tools.account20k_history.report
```

实际资料须存在原本机归档路径。runner仅复用缓存，零网络、零凭证访问；nice=10、单worker、北京时间18:00～19:30在运行边界暂停。每次原件/代码/配置hash核对，已完成run按Manifest恢复而非重算覆盖。新产物位于Git外 `.p1b-archives/account20k-history-20261020-v2/`。

独立复核器只用标准库，自行重建指标、逐日组别/个股决策、向上枚举整手风险数量、费用及现金净值；不调用生产策略或报价函数。该复核不认证供应方许可、原始PIT或投资有效性。
