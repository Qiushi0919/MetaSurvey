# ADR-023: Separate current-observed real research sandbox

Accepted for Wave C by explicit Owner authorization on 2026-10-06. A separate LOCAL_EXPERIMENTAL_REAL_RESEARCH tier consumes fixed, engineering-DQ-eligible gateway observations, retaining all formal source/permission/PIT blockers. It is not an extension of AdmissionReceipt, BrainPacket or ResearchCard. New versioned local artifacts are never accepted by formal or trading consumers.

Current observation means capture available_at <= current frozen decision cutoff. It does not establish a past cutoff's visibility, publication instant, authoritative revision sequence or complete industry history. Raw, financial, action and factor bytes remain immutable; exclusions are preserved. No cloud/model transfer or new gateway request is part of this phase.

The local reports and machine objects remain private 0600 outside Git. Git stores code, methods, schema, hashes and Gate metadata. Official endpoint/agreement references do not verify the custom gateway or confer permission. Provider resolution stays OPEN without halting this Owner-authorized sandbox engineering.
