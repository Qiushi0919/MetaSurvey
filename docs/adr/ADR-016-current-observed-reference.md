# ADR-016 — Current-observed reference clocks and purpose-bound authority

Status: ACCEPTED for the owner's bounded real-slice W1–W3 decision, 2026-10-05. Business/production authority remains blocked. Formal handoff and explicit human decision outrank prior proposals; no historical report is rewritten.

New release1.4.0 extends only new roots `real-slice/` and `contracts/real-slice/`, using ClockEvidence1.0, SourceObservation2.0, SourceAdmissionPolicy2.0, StockSnapshot1.0, AdmissionReceipt2.0, BrainPacket2.0 and FixtureResearchChain1.0. Original contracts, releases, 174 old source pins and SQL001–006 stay byte-identical. StockSnapshot is a strict versioned stock-reference manifest; it is not passed off as the old SnapshotManifest contract. No durable live registry or new migration is claimed.

Publication date and precision are retained separately from nullable publication instant. DATE_ONLY never creates midnight. Actual collector completion establishes retrieved_at, observation_event_at and conservative available_at. It proves present observation, not historical first publication. Business dates can be future dates already announced; their presence cannot certify future price/action/factor/financial availability. Historical admission remains denied.

Admission binds exact observed source/product/category/finite security/date coverage, captured official website terms, purpose LOCAL_CURRENT_OBSERVED_REFERENCE, CORE_40 namespace, projection REFERENCE_FACTS_ONLY, clock version, actual use point and code epoch. The website noncommercial reference role does not grant market-feed, structured financial, cloud, redistribution or historical rights. Tushare is BLOCKED before token access or API network calls because the human reports no verifiable account/product entitlement. No provider-wide trusted flag exists.

Trusted parent construction and pinned normalizer are distinct from consuming a packet. Real collectors are privately branded, fixture/forged collectors and caller normalizers cannot obtain real admission authority. Raw captures and immutable source registration are revalidated on every consume. Consumer-resealed objects, archived signatures alone and fresh issuers cannot restore live permission. Receipt/packet Ed25519 signing keys are generated privately in-process, never exported or archived; public keys permit offline evidence verification only. The local wall clock and HTTPS collector are DEV trust boundaries, not trusted hardware time or production authentication. A hostile host process or monkey-patched runtime is outside this authority model.

Each requested data category reports its own completeness. Today only finite calendar facts and five announcement references per approved stock can be admitted. Neither document titles nor JSON page caches create financial values, action terms, adjustment factors, industry history or full320-session data. latest_trading_session is null until an admitted complete calendar proves it. Holiday Snapshot A is closed, no live price/trigger/tradeability. Snapshot B requires future actual new source data; synthetic invalidation proves mechanics only.

Fixture chain composes frozen implementations and old strict ResearchCard1.0 with a separate version/hash sidecar. Its real grade/Edge/probability/sizing remain UNSET_REQUIRED; a synthetic assessment S only permits REQUEST_REVIEW. Fixture evidence and illustrative semantics coordinate are explicit and separate. Revocation/TTL/upstream supersession invalidates the card without rewriting original records. No real stocks are scored or sent to a model.

Stop after fresh read-only review and Gate. LOCAL_REAL_RESEARCH_GATE may be PARTIAL; other purpose gates remain BLOCKED and redistribution DENIED. P1-B Research Pilot requires a later explicit human authorization and resolved data prerequisites. No account/fee/risk unknown prevents this engineering work, but all still block production.

Pre-delivery independent review found caller-replaceable method receivers and truncated fixture TTL comparison in the initial candidate. The original failed report remains evidence. Repair uses an immutable lexical facade for internal real-source verifiers and strict ISO/calendar parsing plus nanosecond comparisons for new fixture TTL boundaries. Old frozen helpers and business policies are unchanged; final source pin/capture/review must follow the repair.
