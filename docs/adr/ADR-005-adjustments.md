# ADR-005 raw / adjusted price 与 corporate action

状态：P0 工程实现，待 Gate Review。

决定：原始行情不被复权行情覆写。价格口径、调整 id/version、来源 revision、证券和日期共同区分记录；RAW 不绑定复权因素，ADJUSTED 必须绑定明确的调整版本。公司行动及因素修订追加保存，数据集只使用截止前可见行动，调整行情不得早于因素的可得/取得时钟。

财报原始版与修订版也追加保存；as_of 先过滤知道时点，再选可见最新版本，绝不能先取现在最新再回填过去。

未决：供应商因素重建、送转配股、权益处理和实际价格数学核验未实现。旧 V5 只保留原支持范围和 unsupported 事实，不推断完整公司行动能力；不兼容事件必须阻断，而非删除。
