# ADR-002 策略 namespace 与账户共享约束

状态：P0 工程实现，待 Gate Review。

决定：CORE_40、EVENT_3、RESEARCH_6_18M 是唯一 V1 命名空间。研究空间不能生成交易对象。交易合同和持久化关系绑定 mode/account/strategy/security，禁止跨链拼接；旧 V5/V1R 原标签保持 LEGACY，不改名。底层证据可共享，但卡片的账户/模式投影及持仓归属独立。

同一账户的现金、总风险和事件顺序由账户层共享，不能为每个策略复制一份本金。模拟与真实交易物理分表；DEV/PAPER 与 PROD 不可互相写入。

未决：账户内跨策略 lot 调拨、现金预留优先级、净敞口合并规则和全局风险预算尚未获用户决定；不能猜测。P0 只验证明确 lot 归属和按序完整成交的资金守恒，没有并发预留服务。
