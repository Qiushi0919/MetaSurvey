# ADR-034 — Actual capture, external Human roots and isolated Forward counting

Status: ACCEPTED FOR H-A ENGINEERING under Owner instruction; actual activation NOT AUTHORIZED.

Wave G final 43e75c6411c482596844a48267cdf728de05e527 is the frozen starting point. Eight Provider/license/transport facts remain UNKNOWN, thirty actual account/economic settings UNSET_REQUIRED. Source Exception v1 permits only separately authorized, exact-three, LOCAL current-observation reads; it does not grant source admission, historical visibility, transfer or trading.

Actual authority is a separate external trust installation: the Owner installs public Ed25519 keys for HUMAN_USER and a different INDEPENDENT_REVIEWER in the fixed outside-producer operator registry. Producer APIs cannot choose keys, enroll themselves or sign receipts. That registry is intentionally absent in H-A. An ordinary Actor/APPROVE/HUMAN label, a content hash, fixture signature or LLM output is not an authority root. Signatures authenticate the externally enrolled roles; they cannot independently prove a human's intent if the signing key or trusted operator installation is compromised. No privileged-host, Python-interpreter or hostile filesystem-owner resistance is claimed.

Capture, independent acceptance and Forward grants are different closed signed scopes. They bind the frozen code/policy/strategy/baseline/source-schema, exact three symbols, real observed session, original witness/A/capture/snapshot hashes and short expiry. New actions verify real wall-clock validity; old accepted records are reverified against the original signed issued_at, so normal expiry does not rewrite history. Altered configuration or public roots stops reopening; reauthorization is explicit, never automatic. Actual opaque in-process handles reject caller copies/reseals. Persisted public signatures allow independent restart verification without persisting private keys.

The actual-session witness is the separately authenticated Owner's observation plus reopened original evidence. It is not independent supplier authentication or historical PIT evidence. Calendar is_open is planned information; actual open/EOD must be observed and signed after facts exist. Exact-three fresh session bars corroborate that limited current assertion. DATE_ONLY remains a date, publication/first-visible UNKNOWN remains UNKNOWN. Retrieval is current capture visibility, never historical first visibility.

Reference A is the genuine Oct 5 capture with last bars Sep 30, explicitly CURRENT_OBSERVED_REFERENCE_A_NOT_ADMITTED. Capture time and bar date differ and are preserved. A cannot be made historical-admitted by a new policy. Stable request/source-schema version freezes a series; response SHA varies with new daily observations and stays bound per record.

ACTUAL_FORWARD_NO_DECISION uses its own private SQLite suffix and namespace. The Wave G exclusive creation, exact schema/trigger inspection, BEGIN IMMEDIATE expected-head append, record/failure hash chains, duplicate checks and no-auto-repair algorithm are retained. OFFLINE_SIMULATION has a different suffix and can only count simulated sessions; actual_forward_days always 0. Only actual capture + independent reopened acceptance + Snapshot B + separate Human Forward grant can increment the actual store. NO_DECISION / safe_to_trade=false / NO_ORDER / NO_BROKER / NO_MONEY remain invariant; no actual-day count confers native contracts or trading authority.

H-A completes offline implementation, adversarial tests, read-only review, fresh clone and delivery, then STOP. H-B requires fresh Owner instruction, trusted public-key installation, observed market facts, credential presence and separately signed grants. No scheduler. Public evidence-only PIT work does not delay current Forward engineering and does not certify formal price/fundamental PIT.
