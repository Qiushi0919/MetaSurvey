## 调了什么，如何选定

原版P029：RS20、退出MA20、MA退出无等待、止损2×ATR20。

- P009：RS10、退出MA20、持仓第10个交易日起允许MA退出、止损2.5×ATR20。
- P006：同P009，但持仓第5个交易日起允许MA退出。

入场均线、ATR观察期20、20日阶段退出、40日最大持有、风险/现金/整手和原日期化费用不改。持有年龄沿用原版入场日=1；等待只约束MA退出，不延迟ATR止损或40日退出。止损距离参与重新计算可买股数，不以原数量扩大风险。

108组的编号、hash、字典序、选择规则均在[Registration.json](../../experiments/param_opt_v1/Registration.json)于北京时间11:25:51登记；39项搜索实现/上游文件hash于11:27:48封存。全窗原版等价通过后运行新候选。11:31:50锁定，后段输入时间全部晚于锁定；11:31:56完成所有运行。见[CodeFreeze](CodeFreeze.json)、[CandidateLock](CandidateLock.json)、[独立选择复核](Selection-Independent.json)。

候选先满足选择区收益更高且回撤不增、开发区较原版退化不超过预登记5个百分点、30bps压力条件。相邻参数只允许一个轴相邻一步：邻居中位收益须高于原版，至少一半邻居跑赢原版，候选不得比邻居中位数突出超过5个百分点。收益差0.25个百分点内先看低回撤、低换手。28组满足训练条件，事前选前2组；选择区最高收益者已是P009，所以没有再增加第三个参考配置。后段不补选第四组。

P009邻居4组、3组跑赢原版，中位收益20.47%，自身25.39%，距预登记5个百分点尖峰上限较近（差4.91个百分点），应保持谨慎；P006邻居5组均跑赢，中位22.02%，自身21.39%。此离散网格稳定性检查没有多重检验统计校正，不证明显著优越或最优参数。

## 是否只是持仓增加或单股贡献

P009后段平均敞口21.56%，低于原版23.48%；双边换手由13.99降至8.89，手续费由1,135.47降至804.71元，成交由134笔降至100笔。不是简单放大持仓或降低费用假设。

但个股集中影响非常明显：P009中601899贡献11,245.10元，占该配置净利润约30.3%；它相对原版增加7,614.32元，约等于总增益8,127.36元的93.7%。603993和601179等贡献反而下降。此为同run加总归因，**不是删除股票后重新运行的因果实验**，也不能据此改样本。全部九股及三样本组贡献在[结果](Results.json) `contributions`和页面保留。
