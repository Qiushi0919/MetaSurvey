# 参数优化预登记

详见 ../../experiments/param_opt_v1/Registration.json。基线 P029；108组按RS→退出MA→最小持仓年龄→ATR倍数字典积顺序。

开发、选择、检查分别是独立10万元实验，各区预热从2021-06-01开始但预热不交易，不跨区携带仓位。区内不按年重置；保留末40日停止新增及未成交风险。所有区间都是已经暴露的历史。

在选择区相同费用下收益提高且回撤不增，开发区不劣化超过5个百分点，30bps压力下也满足选择区收益/回撤条件；相邻一格参数至少一半跑赢原版、中位超额为正且候选收益不高于邻居中位数5个百分点，才可列稳健候选。收益差0.25个百分点以内先看低回撤、低换手。最多锁定3组（含风险收益参考），之后只看这些组的检查区；不得补第四组。正式推荐还须检查区10/30bps都收益较高且回撤不增，否则明确无稳健推荐。

这些是本轮事先固定的探索性筛选规则，不构成统计显著性校正、实盘门槛或最优参数证明。
