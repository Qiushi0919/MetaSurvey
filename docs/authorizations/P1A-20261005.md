==================================================
5. Micro-Ladder / Incremental Edge Filter
==================================================

这是本系统的重要设计原则。

禁止 AI / 策略因为“显得精确”
生成大量无经济意义的微小价格档位。

例如：

45.20
45.50
45.80

不能天然被视为三个合理买点。


每增加一个 tranche，
必须计算：

incremental_expected_benefit

vs

incremental_transaction_cost


incremental_transaction_cost 至少包含：

新增 commission
新增 minimum-commission effect
新增 slippage
新增 other fees


若：

incremental_expected_benefit

不足以显著覆盖：

incremental_transaction_cost

则拒绝：

REJECT_INSUFFICIENT_INCREMENTAL_EDGE


同时保留：

REJECT_INSUFFICIENT_NET_EDGE
REJECT_INSUFFICIENT_EDGE_COST_RATIO


不要现在擅自确定 safety_multiple 的生产值。

它保持：

UNSET_REQUIRED / EXPERIMENTAL

直到后续回测校准。
