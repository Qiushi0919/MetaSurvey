# T2/T3 quarantine normalization and bounded coverage

`overnight.data.dataset.load_verified_dataset()` takes no caller paths, clocks or authority claims. It checks the frozen G2 Gate, code provenance and all nine source pins, then uses the unchanged `tushare-real-admission/parent/evidence.py` verifier, including its future-publication guard. The two G2 report hashes and all original raw hashes remain authoritative inputs. This operation does not read credentials or make requests.

The result is a deterministic `1.0.1-diagnostic` dataset with 44 requests and 2,786 retained rows. Every request and row stays `QUARANTINED`; source admission is `BLOCKED`, historical visibility is false and production is false. A request preserves its fingerprint, API, category, scope, fixed params, original date scope, units, adjustment label, report/raw hash and original capture clocks. No raw private path occurs in the row sidecars. Source pins use local relative object names; the raw store remains outside Git.

`typed_fields[field]` contains `kind`, `value`, `unit_basis` and, when applicable, `unit` or `precision`. Numbers are lossless Decimal strings, with no rounding or share conversion. Dates remain YYYYMMDD strings with `DATE_ONLY`; published instants remain null. A blank industry `out_date` is `INVALID_DATE_LITERAL` with its original blank value, never null or infinity. Entire responses already blocked by capture DQ stay blocked; normalization does not select valid financial rows for admission. Official product unit descriptions remain references; gateway units and semantics are unverified.

`overnight.data.coverage.analyze_coverage(dataset)` measures the COVERAGE stage and keeps SMOKE separate. The captured calendar contains 492 civil dates and 327 open sessions. Each of the three stocks has 327 raw bars and factors with aligned dates and no observed duplicate or missing session. Empty suspension responses mean unknown status. `pre_close` discontinuities are action-reconciliation questions, not forced equality with prior raw close. There is no weekday-based exchange calendar and no numerical second-source assertion.

The existing SSE reference comparison covers 13 calendar facts and three symbol references only. Names, ST history, raw prices, factors and corporate-action numbers are not independently cross-checked by those references. Completion of bounded engineering coverage cannot establish supplier rights, transport integrity, historical visibility, a Snapshot or an admission receipt.

`normalize_fixture_request()` and `fixture_dataset()` always label injected inputs `SYNTHETIC`. Actual datasets are registered against their canonical bytes; copies or mutation cannot be passed off as the verified object to the analyzer or real-output sink. The dedicated CLI writes new 0600 files exclusively under the approved external overnight data store; symlink traversal and overwrite are blocked. It never rewrites the captures or old project files.

Run the module with the project on the Python path: `python -B -m overnight.data --run-id T2T3-...`. Run focused checks with `python -B -m unittest discover -s overnight/tests -p test_data.py -v`. All fixtures are synthetic; actual checks are read-only replay.
